# 命令（调试 / 查询 / 管理）

所有命令以 `/loot` 开头。**只读命令任意玩家可用；写操作（`/lootadmin`）仅服务器控制台 / 单机聊天可用**（多人聊天会被拒绝，防作弊）。

## 权限规则（H3）

| 通道 | `/loot` 只读 | `/lootadmin` 写操作 |
|---|---|---|
| 单人聊天 | ✅ | ✅ |
| 服务器控制台 | ✅（房主/管理员） | ✅ |
| 多人聊天（任意玩家） | ✅ | ❌ 拒绝（防作弊） |

> 写操作在多人下会改动服务端权威数据（货币等），所以只对能代表服务器的身份开放。

## 只读查询（/loot）

### `/loot info`
查看**手持物品**的词缀详情：
```
rarity=稀有度 tier=档位 power=力量 sockets=插槽数 leg=传说之力 set=套装主题 | [词缀+值] ...
```

### `/loot tier`
查看手持物品的 **tier（档位）**、类别、是否可打宝：
```
tier = 5, cat = MeleeWeapon, eligible = True
```

### `/loot enemy <名称/ID>`
查询**敌人强度分**（秘境池口径：缓存 SetDefaults 值，与模式/种子无关）：
```
/loot enemy 1            → type 1: 蓝史莱姆 life=25 dmg=6 def=0 boss=False power=2.31
/loot enemy 恶魔          → 名称模糊匹配第一个
```
不在秘境缓存（被过滤：友好怪/投射物实体/蠕虫分段/稀有怪等）会提示。

### `/loot riftinfo`
秘境诊断：当前层上限、刷怪池（类型/名称/基础值/强度分/权重）、关底 Boss。
**聊天只显示摘要前 4 行，完整内容写入日志**（`client.log` / `Logs.txt` 搜 `RiftInfo:`）。

## 写操作（/lootadmin）

### `/lootadmin roll <稀有度>`
给手持物品掷稀有度：`none | magic | rare | legendary | set`（或数字 `0-4`）。
掷 `none` = 清空词缀。

### `/lootadmin clear`
清除手持物品词缀（并还原物品售价）。

### `/lootadmin salvage`
拆解手持**带词缀**装备 → 重铸之尘（数量 = 力量 ÷ 拆解除数，默认 2，至少 1）。

### `/lootadmin shards <n>`（或 `/lootadmin 血岩 <n>`）
设置血岩数量（测试用；会同步刷新客户端 UI）。

### `/lootadmin dust <n>`（或 `/lootadmin 重铸之尘 <n>`）
设置重铸之尘数量（测试用；会同步刷新客户端 UI）。

### `/lootadmin gem [类型 等级]`
给手持装备的**第一个空插槽**插入宝石：
- 类型：`ruby / sapphire / emerald / amethyst / topaz / diamond`（或 `0-5`）
- 等级：`0-3`（瑕疵/普通/无瑕/完美）
- 无参：按世界进度随机一颗

要求装备有词缀实例且有空插槽（传说/套装自带 1-2 槽，或已开槽）。

### `/lootadmin spawn <NPC名/ID> [数量]`
在玩家位置刷怪（数量 `1-50`，默认 1）——调试敌人词缀（染色/名字前缀/属性）、秘境怪、Boss 专属效果。
```
/lootadmin spawn 1 10     → 刷 10 只蓝史莱姆
/lootadmin spawn 4        → 刷 1 只 (type 4)
/lootadmin spawn 恶魔 5    → 按名称模糊匹配刷 5 只
```

### `/lootadmin debug pool`
打印手持物品的**可抽取词缀池**（类别过滤后）。完整表写日志（搜 `DebugPool:`），聊天显示前 5 条。

### `/lootadmin debug eaf`
打印**敌人词缀表**：普通池 / 精英池 / Boss 专属池（ID + 名称）。写日志（搜 `DebugEAF:`）。

### `/lootadmin debug power`
打印手持装备的**力量等级构成**：每条词缀值×权重、插槽、传说之力、套装、tier 底数。写日志（搜 `DebugPower:`）。
