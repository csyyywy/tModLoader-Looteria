# 兼容性 / 配置 / 跨模组 API / 命令

## 兼容性设计（对所有物品含其它模组）
- **零新增装备**：不新增武器/护甲/饰品，词缀直接作用于**原版 + 全部其它模组物品**。
- 纯 `GlobalItem` 钩子 + 每物品实例数据（`InstancePerEntity` + `SaveData/LoadData`），不替换物品类型、不动原版 prefix。
- 数值只走**组合式 ref 钩子**（`ModifyWeaponDamage/Crit/Knockback`、`UseSpeedMultiplier`、`ModifyManaCost`、`UpdateEquip`），
  与其它模组的加成顺序叠加共存；绝不直接改 `item.damage/defense`。
- 其它模组的**自定义伤害类**：按继承关系自动映射到近战/远程/魔法/召唤，不认识的类降级为通用伤害，绝不崩溃。
- 全程防御性代码（`TryGetGlobalItem`、加载容错、卸载清静态引用）。

## 跨模组 Mod.Call API
```csharp
Mod loot = ModLoader.GetMod("Looteria");
if (loot != null) {
    bool elig = (bool)loot.Call("IsEligible", item);      // 是否能带词缀
    int rarity = (int)loot.Call("GetRarity", item);       // 0-4
    int power  = (int)loot.Call("GetPowerScore", item);
    loot.Call("RollAffix", item, 3);                      // 掷传说词缀
    loot.Call("ClearAffix", item);
    loot.Call("AddCurrency", player, 100, 50);            // 血岩, 尘
}
```

## 命令
| 命令 | 说明 |
|---|---|
| `/loot info` | 查看手持物品词缀详情（稀有度/tier/力量/插槽/传说之力/套装） |
| `/loot tier` | 查看手持物品 tier、类别、是否可打宝 |
| `/loot enemy <名称/ID>` | 查询敌人强度分（秘境池口径：生命/伤害/防御/强度分） |
| `/loot riftinfo` | 秘境诊断：层上限/刷怪池/关底 Boss（完整信息写日志，聊天给摘要） |
| `/lootadmin roll <稀有度>` | 给手持物品掷稀有度（none/magic/rare/legendary/set 或 0-4） |
| `/lootadmin clear` | 清除手持物品词缀 |
| `/lootadmin salvage` | 拆解手持词缀装备 → 重铸之尘（力量÷拆解除数，默认 2） |
| `/lootadmin shards <n>`（或 `/lootadmin 血岩 <n>`） | 设置血岩（测试） |
| `/lootadmin dust <n>`（或 `/lootadmin 重铸之尘 <n>`） | 设置重铸之尘（测试） |
| `/lootadmin gem [类型 等级]` | 给手持装备插一颗宝石（类型 ruby/sapphire/emerald/amethyst/topaz/diamond 或 0-5；等级 0-3；缺省按进度随机） |
| `/lootadmin spawn <NPC名/ID> [数量]` | 在玩家位置刷怪（调试敌人词缀/秘境怪；数量 1-50） |
| `/lootadmin debug pool` | 打印手持物品的词缀池（完整写日志，聊天给摘要） |
| `/lootadmin debug eaf` | 打印敌人词缀表（普通/精英/Boss 池，写日志） |
| `/lootadmin debug power` | 打印手持装备的力量构成（逐词缀贡献/插槽/传说/套装分解，写日志） |

> **写操作权限（H3）**：`/lootadmin` 系列仅**服务器控制台 / 单机聊天**可用；多人聊天里任何玩家敲写操作都会被拒绝（防作弊）。
> 只读命令 `/loot info|tier|enemy|riftinfo` 任意玩家可用。
> **命令修复**：此前 `/loot shards|dust` 在多人 / 主机模式下"无效"——聊天命令在服务端执行，
> 直接改的是服务端玩家对象，不会同步到客户端（UI 读的是本地玩家），所以看起来没反应。
> 现在命令会广播一条同步包刷新所有端对应玩家的货币；单机直接生效。
> 参数缺失 / 非数字时会明确回复用法，不再静默无反应。
