# 宝石与插槽

## 宝石（实际物品，24 种）
- **6 类型 × 4 等级** = 24 件物品（瑕疵→普通→无瑕→完美），独立图标/名字/稀有度。
- **获取：只由 Boss 掉落**（含模组 Boss），掉落等级随进度：
  - 前期：瑕疵；肉山后：普通；世纪之花后：无瑕；月总后：完美。
- 插槽效果（等级越高越强）：

| 宝石 | 效果（基础每级） |
|---|---|
| 红宝石 | +3% 全伤害 |
| 蓝宝石 | +1.5% 暴击率 |
| 绿宝石 | +2% 移速 + 生命回复 |
| 紫水晶 | +12 最大生命 |
| 黄玉 | +1.5 防御 |
| 钻石 | +1% 减伤 |

## 插槽规则
- **装备最多 6 个插槽**。
- **传说/套装自带 1~2 个**（不占开槽名额）。
- **开槽**（宝石页签选中装备 → "开槽"按钮）：**消耗 1 件同名装备** +1 槽，最多开 4 个。
- 插槽数上限 6 = 自带(≤2) + 开槽(≤4)。

## 页面划分（镶嵌 / 升阶 已分开）
- **「镶嵌」页签**：宝石背包（显示每颗宝石的持有数量）→ 选装备 → 点插槽镶入/取下；开槽也在此页。
- **「升阶」页签**：宝石背包 → 选宝石 → 显示**材料持有量 / 需要量 / 成功率** → 点升阶。

## 镶嵌 / 取下
- 「镶嵌」页签顶部显示**背包里的宝石物品**（图标 + 数量角标），点击选中（高亮）。
- 选中宝石 → 点装备的**空插槽** → 消耗 **1 颗**（从堆叠中扣 1）镶入。
- 点**已镶的插槽** → 取下，**返还宝石物品**（含强化等级）。

## 升阶（DNF 式强化）
- 「升阶」页签选中宝石物品 → 显示「**升阶**（消耗 N 颗同色原版宝石）」按钮，并实时显示：
  - **材料持有量**（如 红宝石 ×7）与**需要量**；**成功率**（带颜色进度条）。
- **材料 = 游戏自带的同名原版宝石**（红宝石升红宝石、钻石升钻石……颜色一一对应），**不再消耗同型本模组宝石**。
- **每次升阶消耗的宝石数 ×1.5**：`消耗数 = ⌈2 × 1.5^当前强化⌉`（0→1 需 2 颗，1→2 需 3 颗，2→3 需 5 颗，3→4 需 7 颗，4→5 需 10 颗……）。
- **每次成功 +10% 宝石属性，无限阶**（强化 +N）。
- **成功率随阶数下降**：`max(30%, 100% - 5%×当前强化)`（+1 阶 95% → 越高越低，最低 30%）。
- **失败只消耗材料**，宝石保留、强化不变。
- 强化等级随宝石物品持久化；镶入/取下/买卖均保留。
- 原版宝石可以从空奖小垃圾、挖矿、宝石树等处获得。
