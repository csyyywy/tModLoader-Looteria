# Looteria · 掠夺之地 —— 玩法说明文档

本目录是模组**完整玩法手册**：所有机制、数据、概率、操作说明。

## 快速开始
1. 安装 Looteria.tmod（放入 `Documents\My Games\Terraria\tModLoader\Mods\` 并启用）。
2. 进世界按 **`P`** 打开**掠夺面板**（单机自动暂停）。
3. 画面左下角**血量前方**会显示当前**力量等级**（占位图标打底，样式后续替换）。
3. 击杀敌人掉落**血岩**（自动入账，战斗文字提示），攒血岩去面板「**抽奖**」页抽装备。
4. 抽到的装备进 **200 格掠夺容器**（格数可配置），点格子=领取到背包，「全部分解」=拆成重铸之尘。
5. 打 Boss 掉**宝石物品**，在「**镶嵌**」页嵌入装备插槽（装备可「开槽」）；在「**升阶**」页用原版宝石强化宝石（+10%/阶，可失败）。
6. 打**秘境**（开启消耗血岩，入侵事件默认 9 分钟，随机关底 Boss）冲层解锁更高档抽奖与更好掉落。

## 操作速查
| 按键/命令 | 说明 |
|---|---|
| `P` | 开/关掠夺面板（单机暂停；含「说明」页 = 游戏内查看全部玩法文档） |
| `/loot roll <稀有度>` | 给手持物品掷稀有度（none/magic/rare/legendary/set 或 0-4） |
| `/loot clear` / `/loot info` / `/loot tier` | 清除词缀 / 查看词缀 / 查看档位 |
| `/loot salvage` | 拆解手持词缀装备 → 重铸之尘 |
| `/loot shards <n>` / `/loot dust <n>` | 设置血岩/重铸之尘（测试） |
