# 货币 / 重铸 / 秘境 / 传说之力 / 套装

## 血岩（Blood Shards）
击杀自动入账（战斗文字提示）：
| 来源 | 基础获取（阶段 0） |
|---|---|
| 普通怪 | 1~3 |
| 精英怪 | 8~15 |
| Boss | 150~300 |
| 秘境通关 | 100×层数 |

**阶段倍率**：掉落随游戏阶段（T0~T7，与抽奖档位解锁一致）从初始 **1x** 线性涨到上限（默认 **10x**，可配置 `阶段掉落倍率上限`）：
| 阶段 | 说明 | 倍率（默认） |
|---|---|---|
| 0 | 初始 | 1x |
| 1 | 克脑/吞世后 | ≈2.3x |
| 3 | 肉山后 | ≈4.9x |
| 5 | 世纪之花后 | ≈7.4x |
| 7 | 月亮领主后 | 10x |

> 总倍率 = 阶段倍率 × 难度倍率（专家 1.5 / 大师 2）× 血岩获取倍率（配置 1~10x）。
> **Boss 掉落加码**：Boss 基础 150~300 血岩（远超精英/普通），配得上 Boss 身份。
> **用途**：抽奖（见《说明-抽奖》）+ 开启秘境（见下）。
> **多人（H5）**：货币是**服务端权威**——击杀在服务端入账后定向 `CurrencyPush` 回推击杀者客户端，
> 客户端不再上行货币（防旧值反向覆盖）；击杀飘字由 `KillNotify` 定向包在击杀者客户端本地渲染。

## 重铸之尘（Reforge Dust）
| 来源 | 获取（阶段 0） |
|---|---|
| Boss / 精英击杀 | 30~60 / 3~7 |
| 拆解词缀装备（/loot salvage 或容器"全部分解"） | `力量等级÷拆解除数`（默认 **2**，≥1） |
| 秘境通关 | 30×层数 |
| 谢谢惠顾券 | 5（默认，可配置） |

同样受**阶段倍率**放大（最高默认 10x）。

**用途**：重铸页签（均消耗钱币，随装备价值上涨；钱币按**原版商店逻辑扣款**——`Player.BuyItem` 自动从背包钱币栏+银行扣取、自动换算找零）——
- 重铸单条：**60 尘 + 装备价值 ÷ 重铸单条钱币除数（默认 50）**（费用可配置；可逐条选择；点「重铸」**立即扣款**并进入**演练**：显示 原词条→新词条，未生效；点「确认重铸」才生效，「取消」不生效且不退款）
- 全部重铸：**20 尘 + 装备价值 ÷ 全部重铸钱币除数（默认 100）**（同样有「确认全部重铸」演练）
- 稀有度升档（成功率可配置，默认 30%，失败不降）：**120 尘 + 装备价值 ÷ 升档钱币除数（默认 50） + 1 件同名装备**（自选消耗）
- 开槽：**40 尘 + 装备价值 ÷ 开槽钱币除数（默认 100） + 1 件同名装备**
- 宝石升阶：原版宝石 + **宝石价值 ÷ 宝石升阶钱币除数（默认 50）**

**钱币 UI（参照原版商店）**：
- **全部按钮换成原版圆角 UI**（`UIPanel` 九宫格贴图：PanelBackground/PanelBorder，悬停亮边框 + 菜单音效，与游戏内其它原版按钮一致）。
- **钱币花销显示在按钮的悬浮框里**（不再挤在按钮内）：鼠标悬停在 重铸单条/全部重铸/升档/开槽/宝石升阶 按钮上时，
  鼠标旁弹出原版 tooltip 背景框，显示「花费 [原版铂金/金/银/铜图标]」（随装备价值实时变化）。
- 各页在操作区上方显示一行**当前钱币**（原版图标）= 你身上+银行全部钱币（同商店口径）。
- 悬浮物品的 tooltip 中，**插槽栏位用原版宝石物品图标显示**（每行 6 个自动换行，空槽灰色槽框，右上角 +N 强化角标）。
- **单机打开面板自动暂停**：打开掠夺面板时单机世界完全暂停（怪物/时间冻结，方便看装备、点按钮）；
  关闭面板恢复。注：原版只对图鉴/设置等内置界面暂停，本面板通过临时启用自动暂停实现，多人不受影响。

## 秘境（Rift = 刷怪海入侵事件）
- 入口：掠夺面板「秘境」页。**开启消耗血岩（层 × 每层费用，默认 50，可配置）**，需求 **掠夺之力 ≥ 层×25（固定，不随难度/种子变化）**。
- **开启后 = 一场刷怪海入侵**：屏幕上方出现自绘的**秘境进度条**（不占用原版入侵，**不会与哥布林入侵挂钩**），时长 **9 分钟（霜月长度，默认，可配置）**。
- **场上敌人数**：至少 **10 只**，并随层数增加 **每层 +1**（受 NPC 上限约束）。**敌人被击杀后快速补充**（每 1/12 秒补一波，缺口大时一波 20 只），始终保持场上密度。
- **敌人全部在屏幕外生成**（生成点**不卡墙**：随机候选 → 找空气列 → 向下找最近的实心/平台地面、站在其上 1 格；60 格内无地面则直接空气格；找不到就跳过下波补；并 clamp 到世界内），从四周涌进来；敌人池来自全部已装模组 NPC（含模组敌人）。**排除非正经敌人**：友好怪、纯弹幕召唤怪（damage≤0）、**投射物实体**（生命<10、可瞬间打掉）、**弹幕/召唤物实体**（会穿墙 `noTileCollide` 且伤害高于自身生命，如克苏鲁之仆——大师 17 血 35 攻，该判定与模式缩放无关，全模式生效）、**蠕虫分段怪**（`aiStyle == NPCAIStyleID.Worm`；realLife 在 SetDefaults 时恒为 -1 无法过滤，单独刷分段会消失/异常）、地牢守卫。
- **刷怪故障隔离**：单只 NPC 类型 NewNPC/AI 抛错（模组怪、异常类型）只记 Error 日志并跳过，**不中断整批刷怪**——入侵进度不会因此归零。
- **首波铺怪翻倍**：开局立即铺 `目标数×2`（上限 80），之后由 Update 每 1/12 秒补波维持密度。
- **刷怪轮换权重**：每次入侵开始时给池里每个类型一个权重（从 0 起）；生成时**优先选权重最低的类型**（并列随机），**刷出成功给该类型 +1**——保证不同敌人轮换出现，而不是总刷同 1~2 种；**每次入侵结束/中止清理权重**。`/loot riftinfo` 会显示每个类型的当前权重 `w=N`。
- **敌人强度与层数对应（乘积对数强度分，用户选定 B；控制数据膨胀、只设上限、不设下限）**：每个敌人按强度分 = `ln(生命) × ln(伤害 × max(1, 防御))`（用**缓存 SetDefaults 原样值**计算，与模式/种子无关 → **各难度同一层选同一批敌人**，实际难度由游戏模式缩放提供；400 万血 Boss 也只有 ~129 分，不膨胀）；
  层数上限 = **自适应首层上限 × 1.068^(层-1)**（首层上限 = 缓存第 15 弱非 Boss 怪强度分，下限 6——首层必含弱怪；**约 33 层 ≈ 首层 9.2 倍强度**）。只要求 `强度分 ≤ 上限`——低级秘境绝不会刷出高级敌人，弱敌任何层都能进池。
- **选池口径与刷出缩放一致（M11）**：池筛选用「缩放后强度」（生命 ×(1+0.15×层)、伤害 ×(1+0.10×层) 后的强度分再比上限），与 `LootGlobalNPC.OnSpawn` 的层缩放同口径，避免"池里合格、刷出即超限被清"的刷-清循环。
- **刷出后实测校验（防 mod 生成时把属性暴缩成超大，如 400 万血 Boss）**：`NPC.NewNPC` 后用「实际生命/伤害 ÷ 缓存 SetDefaults 值」的比值判断；**比值 > 100 即判定异常缩放，立即清除并记日志**（缓存原样存 SetDefaults，合法世界缩放比值天然 1~6，阈值 100 只抓 mod 暴缩这种极端，绝不误杀）。
- **调试命令**：`/loot riftinfo` 输出当前层上限、刷怪池内容（类型 ID + 名称 + 基础值 + 对数强度分 + 当前权重）、关底 Boss —— 与游戏内实际数据对比排查刷怪异常。
- 敌人缩放：生命 ×(1+0.15×层)、伤害 ×(1+0.10×层)；Boss 也缩放。
- **进度**：击杀秘境小怪 **+1**、击杀关底 Boss **+40**、每 10 秒自动 **+1**；**通关需要击败的敌人总量：首层 100，之后每层 +25**（即 `100 + 25×(层-1)`，如 1 层 100 / 2 层 125 / 3 层 150…）。
- **层数无上限 + 自主选择**：开启页可自由选择 **1 ~ 最佳层+1** 任意层（`− / ＋` 或「最佳层 / 下一层」快捷跳转），
  条件只有「通关上一关」+「力量达标」；通关即把最佳层 +1，层数永无封顶，敌人/Boss 池随层数走高。
- **通关奖励**：血岩 100×层、重铸之尘 30×层、必掉稀有+ 一件；解锁下一层；最佳层记录。
- **超时失败可重开**；中止会清除入侵现场（已刷怪消失，多人下经「即死打击」广播双端一致消散，不掉落/不误计进度）。
- **秘境关底 Boss 保证掉落宝石**（即使模组 Boss 没标 boss 旗标）。
- **多人（服务端权威）**：开秘境由客户端发 `RiftStartRequest` → 服务端校验力量/血岩（读服务端账户）→ 扣费 → 刷怪/计时/进度全部在服务端推进 → 进度节流广播（≥60 tick 且 ±5 变化）→ 通关/失败广播结算并逐参战者发奖（血岩/尘/词缀装备定向回推）；清场用 `NetMessage.SendStrikeNPC(InstantKill)` 让客户端本地消散。`BestLevel` 经 `SaveWorldData/LoadWorldData` 按世界持久化（重进保留）。中止走 `RiftAbortRequest` 服务端权威清场。
