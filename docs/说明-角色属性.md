# 角色属性面板（Character Sheet）

按 **`C`** 打开（默认键位，可在设置里改）。单机打开时暂停世界；与掠夺面板（`P`）互斥。

## 布局（刷宝游戏样式）

```
┌────────────────────────────────────────────────────────────┐
│                        角色属性                             │
├──────┬───────────────────┬──────┬──────────────────────────┤
│ 防具 │                   │ 饰品 │ 总览                     │
│ 头盔 │                   │ 饰品 │ 力量: N                  │
│ 胸甲 │   人物立绘         │ 饰品 │ 套装（火焰×2 ✓ 等）      │
│ 腿甲 │  (真实玩家渲染)    │ 饰品 │ 战斗                     │
│      │                   │ 饰品 │ 全伤害加成 +X%           │
│      ├───────────────────┤ 饰品 │ 暴击率 X%                │
│ 手持 │ 坐骑与宠物         │ 饰品 │ …（防御/机动/命中/免疫） │
│      │ 宠物: 虚空精灵     │      │                          │
│      │ 坐骑: 虚空行者     │      │                          │
└──────┴───────────────────┴──────┴──────────────────────────┘
```

- **左**：防具（头盔/胸甲/腿甲）在上，手持武器在下方。
- **中上**：真实玩家渲染（穿当前装备的形象，`Main.PlayerRenderer.DrawPlayer`）。
- **中下**：坐骑与宠物槽（仅显示两格 + 名称）。
- **中右**：饰品槽 `armor[3..9]`（大师模式共 7 格；未解锁的槽 = 变暗 + 对角叉）。
- **右**：属性列表（可滚动），**总览**（力量/套装）+ 详细属性（实时 Player 值，含全部增益/套装/宝石）：
- 所有装备槽**悬停 = 完整悬浮预览**（含词缀/插槽/传说/套装/力量，同掠夺面板）。

## 属性明细

| 区块 | 属性 | 来源 |
|---|---|---|
| 总览 | 力量 | `LooteriaPlayer.GearPower`（10×档位 + Σ词缀 + 插槽/传说/套装） |
| 总览 | 套装 | 各主题已穿件数（×2/×4/×6 阈值，与套装加成同口径） |
| 战斗 | 全伤害加成 | `Player.GetDamage(Generic).Additive`（词缀+套装+宝石+增益） |
| 战斗 | 暴击率 | `Player.GetCritChance(Generic)` |
| 战斗 | 暴击伤害 | `LooteriaPlayer.PassiveCritDamage`（暴伤词缀） |
| 战斗 | 攻击速度 | `Player.GetAttackSpeed(Generic)` |
| 防御 | 生命 / 魔力 | `statLifeMax2 / statManaMax2` |
| 防御 | 防御 | `statDefense`（护甲 + 防御词缀 + 黄玉宝石） |
| 防御 | 减伤 | `endurance`（减伤词缀 + 钻石宝石 + 套装） |
| 防御 | 生命回复 / 魔力回复 | `lifeRegen / manaRegenBonus`（词缀 + 绿宝石） |
| 机动 | 移动速度 | `moveSpeed`（移速词缀 + 套装 + 绿宝石） |
| 命中 | 命中回血 / 回蓝 | `PassiveLifeOnHit / PassiveManaOnHit` |
| 免疫 | 中毒/燃烧/流血/诅咒焰/减速 | `buffImmune`（状态免疫词缀） |

> 数值为**实时值**：换装备/吃增益/套装触发会立即反映。

## 装备槽

- 槽位 = 原版护甲/饰品/手持，**只读预览**（不可交互操作，操作去掠夺面板）。
- 饰品槽 `armor[3..9]`：3-7 = 通用饰品，8 = 恶魔之心（专家第 6 格），9 = 大师第 7 格；未解锁槽显示为变暗 + 对角叉。
- 带词缀的装备有稀有度色框；悬停显示完整 tooltip（每帧克隆，防击退指数爆炸）。
- 时装位（社交槽）不显示（与套装/力量统计口径一致，防作弊）。
- 属性列表超长时显示滚动条（滚轮/拖动）。

## 快捷键

| 键 | 说明 |
|---|---|
| `C` | 开/关角色属性面板（可改键：设置 → 控制 → Looteria 角色属性面板） |
| `P` | 开/关掠夺面板（互斥） |
