# 敌人词缀系统（怪物加强计划 P0）

> 解决"角色已足够强大、敌人太弱"：给全部敌人（普通怪 / 精英 / Boss，含模组 NPC 与秘境怪）附加**随机词缀**（类 D2/POE/GD/LE 精英词缀体系）。

## 核心设计（用户锁定）

1. **词缀在刷出后添加**——不参与秘境强度分筛选。精英照常进秘境池（池筛选只看基础强度分），词缀是生成时的"惊喜"。
2. **野外 + 秘境怪都吃词缀**（秘境层缩放之上叠加）。
3. **Boss 吃普通词缀 + 大量 Boss 专属强化词缀**。
4. **独立配置文件 `EnemyAffixConfig`** 专门管理敌人系统（不塞进 LooteriaConfig）。

## 词缀稀有度与来源

| 档位 | 谁有 | 条数 | 效果档 |
|---|---|---|---|
| 普通词缀 | 普通怪（概率，默认 20%）/ 精英 / Boss | 普通怪 1 条 | 基础 |
| 精英词缀（Champion） | 精英怪（概率，默认 8%） | 2~3 条 | Champion 档翻倍/更强 |
| Boss 专属 | Boss | 1~2 条 | 强化 |

- Boss 总词缀 = 3~4 条普通 + 1~2 条 Boss 专属。
- 普通怪 20% 带 1 条普通词缀（`CommonAffixChance`，可配置）。

## 数值标定

- 全部词缀数值 × `AffixPowerMult`（配置，默认 1）× `(1 + 0.15×阶段)`（阶段缩放，可配置关闭；阶段 7 ≈ 2.05x）。
- 属性乘数（生命/伤害）clamp 到配置上限（默认 4x），防词缀+模式+层缩放叠加爆炸。
- 减伤 clamp 0.8、吸血 0.5、再生 0.1、移速 0.6；荆棘为**固定反伤**（荆棘 15 / 荆棘王冠 30，× AffixPowerMult×阶段，不随玩家伤害放大）。

## 实现（`Common/Globals/EnemyAffixGlobalNPC.cs`）

- `GlobalNPC`，`InstancePerEntity = true`，作用于非友好且伤害 >0 的 NPC。
- `OnSpawn`（仅服务端/单机）：按 Boss/精英/普通掷取词缀 → `ApplyStats` 应用属性（lifeMax/life/damage/defense）并记录 `LifeMult/DamageMult`。
- `ModifyIncomingHit`：减伤% 词缀（各端同输入同输出，幂等）。
- `OnHitPlayer`（服务端守卫）：减益附加 + 吸血回血。
- `OnHitByItem/OnHitByProjectile`（服务端守卫）：荆棘固定反伤。
- `AI`（服务端守卫）：再生 / 迅捷移速近似 / 狂怒二阶段 / 风暴之眼周期弹幕。
- `OnKill`（服务端守卫）：分裂 / 召唤 / 爆炸。
- `ModifyTypeName` + `DrawEffects`：名字加词缀前缀（如「狂暴的骷髅」）+ 按稀有度染色（普通蓝、精英紫、Boss 金）——纯表现，各端都执行。
- `SendExtraAI/ReceiveExtraAI`：同步 `Rarity + 词缀 id 列表`（服务端 → 客户端；属性本身随 SyncNPC 下行）。

## 与秘境强度分的关系

- **词缀不进强度分**：池筛选 / 层上限 / 轮换权重 / 生成点全部不动（用户决策 1）。
- **刷出后实测防线分母改为预期值**：`缓存 SetDefaults 值 × 层缩放 × 词缀倍率（LifeMult/DamageMult）`。
  合法叠加（词缀 + 层缩放 + 大师/FTW 模式缩放）比值天然 ~1~6；阈值 100 只抓 mod 生成时暴缩（400 万血 Boss）这种极端，绝不误杀。

## 掉落加成（LootGlobalNPC 改动）

- 原 OnSpawn 精英逻辑（×1.8/×1.2 硬乘）**删除**——由词缀系统替代。
- 精英判定 = `EnemyAffixGlobalNPC.Rarity == Champion` 或带词缀的非 Boss。
- 精英货币掉落 × `(1 + 词缀数 × EliteDropBonusPerAffix)`（默认 0.15，3 词缀精英 +45%）。

## 配置项（`EnemyAffixConfig`，全部可调）

| 项 | 默认 | 范围 |
|---|---|---|
| Enable（总开关） | true | — |
| CommonAffixChance（普通怪词缀概率） | 0.20 | 0~0.5 |
| EliteChance（精英率，自 LooteriaConfig 迁移） | 0.08 | 0~0.5 |
| EliteAffixCountMin/Max | 2 / 3 | 1~6 |
| BossAffixCountMin/Max | 3 / 4 | 0~8 |
| BossExclusiveCountMin/Max | 1 / 2 | 0~4 |
| AffixPowerMult（词缀数值倍率） | 1 | 0.25~3 |
| LifeMultCap / DamageMultCap | 4 / 4 | 1~10 |
| StageScaling（阶段上浮） | true | — |
| ShowAffixInName（名字前缀） | true | — |
| EliteDropBonusPerAffix（精英掉落加成） | 0.15 | 0~1 |
| ExcludedNpcs（排除列表，按显示名） | 空 | List |
| **AffixValueOverrides（词缀数值覆盖）** | 空 | Dictionary<string,float> |

> **词缀数值覆盖（AffixValueOverrides）**：逐词缀数值倍率覆盖。key = 词缀英文 Key（Strong/Berserk/Ironhide/Swift/Regen/Thorns/Vampiric/Split/Summoner/Explosive/Apocalypse/Immortal/Annihilation/ElementLord/Warlord/SplitRampage/ThornsCrown/VampireLord/StormEye/Fury/SwiftHunter/Unbreakable），value = 倍率（0 = 默认，用全局 AffixPowerMult）。
> 例：`{"Strong": 3}` → 强壮生命加成 ×3；`{"Thorns": 0}` → 关掉荆棘反伤；`{"Annihilation": 0.5}` → 湮灭爆炸半径减半。
> 适用于：生命/伤害/防御/减伤/荆棘/吸血/再生/移速/爆炸半径/分裂比例（数值类词缀全部可覆盖）。

> `LooteriaConfig.EliteChance` 字段保留（防旧配置引用），但代码不再读它——精英率以 `EnemyAffixConfig.EliteChance` 为准。

## 多人

- 词缀只在服务端掷取（客户端 `OnSpawn` 早退），经 `SendExtraAI/ReceiveExtraAI` 下行词缀列表——避免双端 rand 不同步。
- 属性改动在服务端 `OnSpawn` 后随 `SyncNPC` 下行。
- 减益 / 荆棘 / 吸血 / 弹幕 / 分裂全部带 `if (Main.netMode == MultiplayerClient) return;` 服务端守卫（铁律 6.5）。

## 边界与失败模式

- **AI 重写冲突**：迅捷/风暴之眼只做轻量近似（每帧乘速度、周期弹幕），不碰 AI 状态机；分裂/召唤只 NewNPC 小怪，不复制 Boss AI 复杂行为。
- **Boss 强度崩坏**：Boss 词缀数值受 LifeMultCap/DamageMultCap + AffixPowerMult 双重钳制；`ExcludedNpcs` 可逐名排除。
- **配置兼容**：新配置全新创建（无旧档）；`LooteriaConfig.EliteChance` 保留字段防旧配置引用错乱。

## 测试

- `SelfTestSystem` 新增 `enemy-affix` 用例：强制精英掷取 → 断言词缀非空、倍率记录、属性已乘、`SendExtraAI/ReceiveExtraAI` 往返一致、RiftSystem 防线新分母比值 ≈1。
- 无头流程维持**只验证构建**（用户指令不变）：`-ValidateOnly` 默认开，构建成功即 PASS。
